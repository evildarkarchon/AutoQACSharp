# Own durable Discovery settings change acceptance

Accepted: deepen the existing Discovery settings change module so one intent/result interface owns disk persistence, supersession, and acceptance of a matching Plugin refresh publication; publication rows, discovery planning, and Issue approximation remain behind their existing seams. Acceptance precedes approximation completion, independent setting choices may share a matching publication, and a failed or canceled refresh preserves already-saved choices while cleaning remains blocked until matching publication succeeds, deliberately avoiding rollback that would discard the user's choice. Main-window, Settings dialog, and Skip list edits use the same module; shared admission excludes mutations during Cleaning session startup and execution, Reset fences older changes, and external changes invalidate pending acceptance while retaining existing reload deferral and automatic-refresh behavior.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backup metadata/config paths -> filesystem | Local paths from backup metadata and configuration are used for copy/delete operations. |
| background copy callbacks -> Avalonia UI state | Progress callbacks from async file I/O cross into UI-bound ViewModel properties. |
| service outcomes -> user-facing UI | Technical filesystem exceptions become concise UI labels and structured result rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-08-01 | Tampering | `BackupService.RestorePluginRowAsync` / backup metadata paths | mitigate | Preserve existing metadata validation before copy: simple non-rooted `FileName`, session-contained `backupPath`, rooted normalized `OriginalPath`. |
| T-07-08-02 | Information Disclosure | `BackupService.BackupPluginAsync` / restore UI failures | mitigate | Return `BackupFailureReason` labels (`Access denied`, `Target folder creation failed`) and log technical exception details instead of displaying raw paths/stack traces. |
| T-07-08-03 | Denial of Service | `CleanupOldSessionsAsync` cancellation gates | mitigate | Convert expected cancellation to structured canceled cleanup results with rows/counts so cleanup stops predictably without crashing the cleaning finalization path. |
| T-07-08-04 | Tampering | `RestoreViewModel` progress callbacks | mitigate | Marshal progress callbacks through `IUiDispatcher.Post` before mutating UI-bound properties, preventing off-thread UI state mutation. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user confirmation → overwrite operation | Restore overwrites local plugin files only after explicit confirmation. |
| restore result → restore UI | Row-level failure text is visible to user. |
| cancel button → file-copy cancellation token | UI cancellation must stop active copy and cleanup partial output through service. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04-01 | Tampering | restore overwrite commands | mitigate | Require confirmation for Restore Selected and Restore All before calling service. |
| T-07-04-02 | Information Disclosure | restore result rows/dialogs | mitigate | Bind only concise result reason display strings; no raw exception detail in UI. |
| T-07-04-03 | Denial of Service | active restore copy | mitigate | Provide `Cancel Restore` command and disable conflicting restore/delete/refresh actions while active. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file operation progress → UI state | Progress text is shown to user and must avoid raw paths. |
| backup/retention service → final session result | Warning/cancel outcomes must not be lost during session finalization. |
| cancellation request → orchestrator sequencing | Canceling file work must not corrupt sequential xEdit launch ordering. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-01 | Tampering | backup-before-xEdit sequence | mitigate | Tests assert awaited per-plugin backup occurs immediately before each `CleanPluginAsync` call and canceled backup prevents that plugin launch. |
| T-07-03-02 | Information Disclosure | file operation progress labels | mitigate | Use plugin file names and fixed phase labels, not full paths or exception text. |
| T-07-03-03 | Denial of Service | backup/retention cancellation | mitigate | Route cancellation tokens to async backup/retention calls and clear file-operation state after completion/cancel. |
</threat_model>

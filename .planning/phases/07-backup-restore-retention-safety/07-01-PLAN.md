<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backup metadata/config → filesystem copy | Source and destination paths are local but can be stale or edited outside AutoQAC. |
| filesystem exceptions → UI-facing result text | Technical exception messages can include paths and must not become display text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Tampering | `BackupFileCopier.CopyAsync` destination handling | mitigate | Delete partial destination files on cancellation/incomplete failures and report `Canceled`/concise failure reasons instead of counting as success. |
| T-07-01-02 | Information Disclosure | `BackupOperationResult` display strings | mitigate | Map exceptions to fixed reason strings and keep raw exception details out of result display fields. |
| T-07-01-03 | Denial of Service | long file copy | mitigate | Use async copy with cancellation token and progress reporting so UI can cancel active copy work. |
</threat_model>

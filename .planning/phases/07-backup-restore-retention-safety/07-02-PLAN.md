<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backup session metadata → restore destination | `OriginalPath` from `session.json` controls local write target. |
| backup root directory → retention deletion | Directory enumeration chooses sessions to delete. |
| filesystem exception → service result | Exceptions can include local path detail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | `RestoreSessionAsync` | mitigate | Validate backup file existence, create only target directory for each entry, use structured failure rows, and continue remaining rows without treating failures as success. |
| T-07-02-02 | Denial of Service | `CleanupOldSessionsAsync` | mitigate | Respect cancellation and retry deletion once only; do not loop indefinitely on locked directories. |
| T-07-02-03 | Information Disclosure | restore/retention result reasons | mitigate | Return fixed concise reasons and log exception details through `ILoggingService`. |
| T-07-02-04 | Tampering | retention deletion selection | mitigate | Compare full paths case-insensitively to protect current session and keep newest configured sessions before building delete list. |
</threat_model>

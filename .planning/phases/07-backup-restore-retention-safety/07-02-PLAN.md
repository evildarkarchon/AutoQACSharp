| backup root→retention delete | Directory enumeration decides which local sessions are deleted. |

| T-07-02 | T/I | BackupService.RestoreSessionAsync | mitigate | Recreate only the target entry directory, map expected failures to fixed labels, and log technical exception details without exposing raw paths in results. |
| T-07-03 | T/D | BackupService.CleanupOldSessionsAsync | mitigate | Exclude `currentSessionDir` before delete selection and keep newest `MaxSessions`; retry once then keep failed-delete sessions. |

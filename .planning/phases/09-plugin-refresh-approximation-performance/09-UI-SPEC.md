## Interaction Contract

### Placement

- Add `Refresh selected approximations` near the existing plugin list header controls (`All`, `None`, `Manage Skip List`) because the action operates on selected plugin rows.
- If a `Cancel refresh` action is visible, place it adjacent to the refresh CTA only while approximation refresh is running.
- Do not move global cleaning controls (`Preview`, `Start Cleaning`, `Stop`) for this phase.

### Command Enablement

| Control | Enabled When | Disabled/Hidden Reason |
|---------|--------------|------------------------|
| Refresh selected approximations | Stable plugin list is loaded, not cleaning, approximation support exists for the selected game, and at least one visible plugin row is selected/checked | Show disabled state; status/tooltip may say `Select plugins to refresh.` or `Approximation refresh is not available for this game.` |
| Cancel refresh | Approximation refresh generation is actively running | Hidden or disabled otherwise |
| All / None | Preserve existing behavior; continue disabled while cleaning | Existing selection behavior remains source of selected target set |

Selection means checked visible plugin rows (`PluginListItem.IsSelected == true`), not merely the focused `ListBox.SelectedItem`. Snapshot the checked visible target set when refresh starts; later selection changes do not mutate active work.

### Progress And Row Updates

- Load and display plugin rows before approximation analysis begins.
- Show truthful item-count progress: `Analyzing {current} of {total} selected plugins.`
- Update rows incrementally as each plugin result arrives.
- Non-targeted rows keep existing approximation values.
- Not-yet-analyzed rows keep previous value or `Unavailable`; do not clear rows on cancellation/supersede.
- Per-plugin failures mark only that row `Unavailable` and log detail; do not interrupt with a dialog.

### Cancellation And Supersede

- Manual cancel is immediate, non-destructive, and does not ask for confirmation.
- Manual cancel status: `Approximation refresh canceled.`
- Starting a newer refresh cancels/replaces the old generation silently; show only the newer generation status.
- Starting cleaning cancels active approximation refresh silently so Mutagen/file I/O does not compete with the primary sequential cleaning workflow.

### Accessibility And Keyboard

- CTA and cancel actions must be standard `Button` controls with command bindings so keyboard activation and disabled semantics come from Avalonia.
- Provide tooltip/help text for disabled unsupported-game state if status text alone would be transient.
- Keep row text readable at 11px minimum and use Fluent theme contrast resources for secondary text.

| Boundary | Description |
|----------|-------------|
| Progress UI→Process control | User action in Progress window determines whether process force termination is requested. |
| Process outcome→Progress UI | Termination results become persistent user-facing warning text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Elevation of Privilege | `ProgressViewModel.StopAsync` | mitigate | Force stop only on `MessageDialogResult.Yes` after `GracePeriodExpired`; tests assert no pre-confirm force call. |
| T-12-05 | Repudiation | `ProgressViewModel` outcome warnings | mitigate | Persist left-running/force-failure outcome text in summary area so user can see what happened after transient controls disappear. |
| T-12-06 | Information Disclosure | Progress warning/dialog copy | mitigate | Reuse Phase 11-safe `StopTerminationDialogContent` strings; never interpolate exception, path, or command data. |
| T-12-07 | Denial of Service | Hang Kill path | accept | Immediate hang kill is an explicit existing user action per D-09; plan preserves it and only adds failure reporting. |
</threat_model>

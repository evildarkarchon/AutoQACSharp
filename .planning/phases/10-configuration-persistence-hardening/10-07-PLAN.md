**Fix 1 — Conditional reload flag clearing (gap 1 from VERIFICATION.md):**

Modify `ConfigurationService.ReloadFromDiskAsync` to only clear `_hasPendingUserSave` when the reload succeeds:

```csharp
public async Task ReloadFromDiskAsync(CancellationToken ct = default)
{
    ThrowIfDisposed();
    await _consumerTask.ConfigureAwait(false);
    var result = await _coordinator.ReloadFromDiskAsync(ct).ConfigureAwait(false);

    // Only clear facade state when the reload actually succeeded.
    // A failed or rejected reload must not discard the pending-save
    // indicator — the coordinator (after Plan 06) flushes pending
    // saves before reading disk, so a successful result means the
    // user's edits are persisted and the reload applied fresh content.
    if (result.Status is ConfigPersistenceStatusKind.Success)
    {
        lock (_stateLock)
        {
            _loadedUserConfigFromDisk = true;
            _hasPendingUserSave = false;
        }
    }

    lock (_stateLock)
    {
        _mainConfigCache = null;
    }
}
```

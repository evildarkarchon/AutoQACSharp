<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk YAML <-> in-memory config | YAML on disk is partially trusted: external editors or other tools may write malformed/hostile YAML. Validation happens INSIDE the coordinator before any state replacement (D-11, D-19). |
| Coordinator <-> ViewModels | Failure payloads cross this boundary as `ConfigPersistenceFailure` records carrying ONLY safe summary strings — no exception types, no stack traces (D-28). |
| Watcher <-> Coordinator | `FileSystemWatcher` events are unreliable signals; the coordinator re-reads file content before deciding (D-08). |

**Gap 2 fix — Observer-exception safety:**

Add three private helper methods to ConfigPersistenceCoordinator that wrap Subject.OnNext in try/catch:

```csharp
/// <summary>
/// Publishes to the configuration-accepted subject without letting observer exceptions
/// escape into the single-reader operation loop. Observer throws are logged and swallowed
/// because the coordinator must always complete caller TaskCompletionSources.
/// </summary>
private void SafePublishAccepted(UserConfiguration config)
{
    try { _configurationAccepted.OnNext(config); }
    catch (Exception ex) { _logger.Warning("[ConfigPersistence] Observer exception on ConfigurationAccepted: {Message}", ex.Message); }
}

/// <summary>
/// Publishes to the persistence-results subject without letting observer exceptions
/// escape into the single-reader operation loop.
/// </summary>
private void SafePublishResult(ConfigPersistenceResult result)
{
    try { _persistenceResults.OnNext(result); }
    catch (Exception ex) { _logger.Warning("[ConfigPersistence] Observer exception on PersistenceResults: {Message}", ex.Message); }
}

/// <summary>
/// Publishes to the failures subject without letting observer exceptions
/// escape into the single-reader operation loop.
/// </summary>
private void SafePublishFailure(ConfigPersistenceFailure failure)
{
    _lastFailure = failure;
    try { _failures.OnNext(failure); }
    catch (Exception ex) { _logger.Warning("[ConfigPersistence] Observer exception on Failures: {Message}", ex.Message); }
}
```

```csharp
private async Task ApplyReloadRequestAsync(ReloadRequest reload, CancellationToken ct)
{
    // Guard: explicit reloads must not silently overwrite a queued app save.
    // Flush the pending save first so the latest user edits reach disk before
    // the reload reads disk content back.
    if (_pendingApp != null)
    {
        _logger.Information("[ConfigPersistence] Flushing pending app save before explicit reload");
        var flushResult = await FlushPendingInsideConsumerAsync(ct).ConfigureAwait(false);
        SafePublishResult(flushResult);
    }

    var read = await ReadForReloadAsync(ConfigPersistenceOperationKind.Reload, ct).ConfigureAwait(false);
    var result = read.Result ?? ValidateAndApply(read.ReadResult, ConfigPersistenceOperationKind.Reload);
    SafePublishResult(result);
    reload.Completion.TrySetResult(result);
}
```

This ensures the user's pending save is written to disk before the reload reads it back, so the user's edits are not lost. The flushed content becomes the disk content, and the reload sees the latest.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| second app process→shared PID store | Duplicate app instances could otherwise race process/PID state. |
| test runner→helper process | Integration tests spawn local processes that must be bounded and cleaned up. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Denial of Service | duplicate app startup | mitigate | Acquire named mutex at startup and shut down duplicate instances before watchers/workflows start. |
| T-05-04-02 | Information Disclosure | duplicate-instance dialog | mitigate | Use UI-SPEC primary copy without mutex name, PID, or local paths. |
| T-05-04-03 | Denial of Service | process integration tests | mitigate | Use bounded helper modes and `finally` cleanup with `Kill(entireProcessTree: true)`. |
</threat_model>

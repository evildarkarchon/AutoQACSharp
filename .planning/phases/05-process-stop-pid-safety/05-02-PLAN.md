<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user cancellation→process service | Caller cancellation intent must not be misinterpreted as permission to force kill. |
| Windows process API→AutoQAC result model | `Kill(true)` and `WaitForExitAsync` can fail or only prove root-process exit. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Denial of Service | `ExecuteAsync` | mitigate | Separate timeout and user-stop reasons so user Stop cannot force-kill before confirmation. |
| T-05-02-02 | Repudiation | `TerminateProcessAsync` | mitigate | Return `ForceKillFailed` on kill/wait exceptions and log exception details. |
| T-05-02-03 | Tampering | orphan cleanup | mitigate | Filter PID cleanup by session ID and process identity instead of clearing all entries. |
</threat_model>

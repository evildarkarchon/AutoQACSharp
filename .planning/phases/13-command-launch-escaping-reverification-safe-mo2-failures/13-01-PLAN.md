From `AutoQAC/Services/Cleaning/XEditCommandBuilder.cs`:
```csharp
public interface IXEditCommandBuilder
{
    ProcessStartInfo? BuildCommand(PluginInfo plugin, GameType gameType);
}
```

Current required command-builder behavior:
- `BuildCommand` returns `null` when `gameType == GameType.Unknown`.
- `BuildCommand` returns `null` when `XEditExecutablePath` is null or empty.
- If `CurrentState.Mo2ModeEnabled` is `true` and `Mo2ExecutablePath` is null, empty, or whitespace, `BuildCommand` returns `null` before any direct xEdit `ProcessStartInfo` can be built.
- Direct mode sets `UseShellExecute = false`, keeps `Arguments` empty, and adds parsed `ArgumentList` tokens including `-QAC`, `-autoexit`, `-autoload`, and exact `plugin.FileName`.
- Configured MO2 mode sets `UseShellExecute = false`, `FileName = Mo2ExecutablePath`, and `ArgumentList = ["run", xEditPath, "-a", BuildMo2NestedPayload(args)]`.

From `AutoQAC/Services/Cleaning/CleaningService.cs`:
```csharp
public async Task<CleaningResult> CleanPluginAsync(
    PluginInfo plugin,
    CancellationToken ct = default,
    Action<System.Diagnostics.Process>? onProcessStarted = null)
```

Current required cleaning-service behavior:
- `commandBuilder.BuildCommand(...) == null` returns failed `CleaningResult` with `No process was started` and does not call `IProcessExecutionService.ExecuteAsync`.
- Unexpected exceptions are logged with `logger.Error(ex, "Error cleaning {Plugin}", safePluginName)` and return `DiagnosticTextFormatter.CleaningFailedForPlugin(plugin.FileName)`.
- Launch logs use operation/mode/game/plugin/argumentCount/status fields and must not reconstruct raw argv payloads.

From `AutoQAC/Services/Process/ProcessExecutionService.cs`:
```csharp
public async Task<ProcessResult> ExecuteAsync(
    ProcessStartInfo startInfo,
    TimeSpan? timeout = null,
    CancellationToken ct = default,
    Action<System.Diagnostics.Process>? onProcessStarted = null,
    string? pluginName = null)
```

Current required process-boundary behavior:
- `CloneStartInfoForLaunch` copies every `startInfo.ArgumentList` entry into the launched `ProcessStartInfo`.
- Legacy `Arguments` is preserved only when `ArgumentList.Count == 0`.
- Process diagnostics record argument counts, not raw arguments.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cleaning callback → ViewModel dialog request | Runtime plugin/error strings from cleaning callbacks become user-facing text. |
| ViewModel/dialog service → Avalonia TextBlock | Dialog service renders strings directly to UI controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-12-01 | I | `CleaningCommandsViewModel.HandleTimeoutRetryAsync` | mitigate | Sanitize callback `pluginName` with `DiagnosticTextFormatter.SafePluginName` before composing retry dialog copy. |
| T-11-12-02 | I | `CleaningCommandsViewModel.HandleBackupFailureAsync` | mitigate | Sanitize callback `pluginName` and pass `errorMessage` through `SafeFailureSummary` with a latest-log fallback before calling the dialog service. |
| T-11-12-03 | I | `MessageDialogService.ShowBackupFailureDialogAsync` | mitigate | Apply the same formatter defensively before assigning TextBlock text, so future callers cannot bypass the safe UI boundary. |
</threat_model>

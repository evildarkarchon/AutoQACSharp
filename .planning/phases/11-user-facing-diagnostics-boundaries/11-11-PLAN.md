| AutoQAC result model -> ProgressWindow tooltip | `PluginCleaningResult.LogParseWarning` is bound directly to `ToolTip.Tip` and is user-facing. |
| AutoQAC result model -> local logs | Raw warnings may be logged locally when they identify the direct failed local resource needed for troubleshooting. |

| T-11-11-02 | I | `XEditLogFileService` / local logs | accept | Raw main-log path remains in local debug/warning logs only as the direct failed local resource permitted by D-14. |
| T-11-11-03 | T | `ProgressWindow.axaml` tooltip binding | mitigate | Leave the binding unchanged and make the bound model property safe; add a regression that fails if unsafe warning text reaches the bound value. |
